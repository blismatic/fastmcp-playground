Lightning Docs MCP

Allows an AI assistant to query and generate reports on your Lightning Docs data.

Upon your first time connecting, you'll be asked to log in to your Lightning Docs account via Auth0.

Connect your assistant

Select your AI client below and follow the steps.

May require an Enterprise/Edu account or a Business account with ChatGPT.

  1. Go to "Plugins" in the top left.
  2. Click the "Add" dropdown in the top right → Add custom MCP server.
  3. Give the server a name, such as Lightning Docs MCP.
  4. Under connection type, leave it as "Server URL".
  5. Paste the server URL from above into the connection field.
  6. Authentication: choose OAuth.
  7. Check the "I understand and want to continue" checkbox.
  8. Select "Create as a plugin" → "Connect Lightning Docs".
  9. Upon your browser opening, click the green "Allow Access" button.
  10. Log in to your Lightning Docs 3.0 account.

For developers / more advanced users.

  1. Open your terminal of choice.
  2. Add the server, replacing <server-name> with any name of your choice:
    3. claude mcp add --transport http <server-name>
  3. Authenticate with the MCP server. Your browser should automatically open to complete the authentication process.
    4. claude mcp login <server-name>
  4. Click the green "Allow Access" button.
  5. Log in to your Lightning Docs 3.0 account.

    6. To remove the server, simply run claude mcp remove <server-name>.
